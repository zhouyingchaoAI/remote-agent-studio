# 每日速览 · 开源项目集成说明

「速览」页有两个数据源,可随时切换。

## 数据源一:codex 直接检索(开箱即用)

让当前引擎(codex / claude / DeepSeek / 国产模型)联网检索,产出资讯、产品创意、论文、开源项目四栏。零部署,但结果质量取决于模型的检索能力。

提示词与解析逻辑在 `electron/brief.js`,输出被强约束成 JSON 并做了容错解析、链接白名单(只允许 http/https)、脏数据丢弃。

## 数据源二:PrismFlowAgent(流光)· 推荐

[PrismFlowAgent](https://github.com/justlovemaki/PrismFlowAgent) 是开源的自动化资讯聚合系统:抓 GitHub Trending、学术论文、RSS、社媒,用 AI 深度总结,支持定时无人值守。它**原生为外部 AI Agent 接管而设计**,提供 `/api/ai/v1/*` 接口。

### 部署(让 codex 代劳)

设置 → 资讯聚合 → 「复制部署指令」,把内容粘到对话里发给 codex,它会自动 clone、装依赖、启动,并回报实际端口。也可手动:

```bash
git clone https://github.com/justlovemaki/PrismFlowAgent.git
cd PrismFlowAgent && npm install && (cd frontend && pnpm install)
npm run dev:all          # 后端 3000,前端 5173(默认密码 admin123)
```

### 接入

设置 → 资讯聚合 → 填服务地址(默认 `http://localhost:3000`)→ 点「注册并授权」。应用会调 `POST /api/ai/v1/register` 拿到 apiKey 并自动打开激活链接,你在浏览器点「确认并批准接入」即完成。状态栏会显示「已连接并授权」。

之后到「速览」页把数据源切到 PrismFlowAgent,选一个它的 Agent / Workflow 运行即可。若输出是结构化速览 JSON,自动渲染成四栏卡片并存为当日速览;不是的话原样展示文本,不硬塞进卡片。

### 凭据安全

apiKey 用系统 safeStorage 加密后存在本机 `userData/prismflow.json`,不回显到界面、不进日志。

## 为什么是"调用"而不是"把代码搬进来"

PrismFlowAgent 采用 **GPL-3.0**,本项目是 **MIT**。把 GPL 代码并入本仓库再分发,会要求整个 Remote Agent Studio 转为 GPL-3.0(传染性)。当前实现是**进程分离的 HTTP 调用** —— 两个程序各自独立运行、通过网络接口通信,不构成 GPL 意义上的衍生作品,因此本项目可继续保持 MIT。

集成代码全在 `electron/prismflow.js`(客户端)与界面层,仓库里没有任何一行流光的源码。

> 以上是常见的工程实践判断,不构成法律意见。若你打算把本项目商业化分发,建议就具体分发形态咨询专业律师。

## 其它可选的开源项目

调研时的备选,按需自取:

- [TrendRadar](https://github.com/sansan0/TrendRadar) — 多平台热点聚合 + 关键词精筛 + AI 简报,Docker 部署,支持 MCP 接入
- [NewsNow](https://github.com/ourongxing/newsnow) — 优雅的实时资讯聚合,内置 GitHub / HN / V2EX / 知乎等源
- [RSSHub](https://github.com/DIYgod/RSSHub) — 万物皆可 RSS,1000+ 路由(含公众号、arXiv、GitHub Trending)
- [daily-paper-reader](https://github.com/ziwenhahaha/daily-paper-reader) — 每日 arXiv / OpenReview 论文推荐与 AI 问答
- [zotero-arxiv-daily](https://github.com/TideDra/zotero-arxiv-daily) — 按 Zotero 库推荐当日 arXiv,AI TL;DR,GitHub Action 零成本运行

这些同样建议以"独立部署 + 接口调用"的方式接入,注意各自的许可证。
