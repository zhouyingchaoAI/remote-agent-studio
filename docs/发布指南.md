# 发布指南(维护者手册)

> 覆盖:版本发布流程、签名与公证、演示 GIF 分镜、渠道发布清单。

## 一、版本发布流程

日常开发合入 main;发版时更新 `package.json` 版本号,提交后打 tag 推送:

```bash
git tag v0.2.0 && git push origin v0.2.0
```

`.github/workflows/release.yml` 会自动在三平台构建 dmg / nsis / AppImage 并创建 GitHub Release(草稿),人工补写 changelog 亮点后发布。Release 发布后,应用内 electron-updater 会自动提示用户更新(需 `package.json` 的 `build.publish` 指向你的仓库,推送前把 `OWNER` 替换为 GitHub 用户名——README 徽章里的同名占位也一起换)。

changelog 写法:每版三段式——一句话主题、2-4 个用户可感知的变化(带截图/GIF 更好)、破坏性变更与致谢。这段文字同时就是你发推/即刻的素材。

## 二、签名与公证(需要你本人操作一次)

**macOS**(没有这步,用户打开会遇到"无法验证开发者"):

1. 注册 Apple Developer Program($99/年),在 developer.apple.com 生成 **Developer ID Application** 证书,导出为 .p12。
2. App Store Connect → 用户与访问 → 密钥,生成 API Key(或用 Apple ID + app 专用密码)。
3. 在 GitHub 仓库 Settings → Secrets 添加:`MAC_CERT_P12_BASE64`(证书 base64)、`MAC_CERT_PASSWORD`、`APPLE_ID`、`APPLE_APP_SPECIFIC_PASSWORD`、`APPLE_TEAM_ID`。
4. release.yml 已预留这些 secrets 的注入;electron-builder 检测到证书会自动签名,`build.mac.notarize: true` 已配置,公证自动完成。没配 secrets 时构建照常出未签名包(本地测试用)。

**Windows**:代码签名证书(OV 约 $70-200/年,EV 更贵但免 SmartScreen 冷启动)。副业阶段可先不签,NSIS 安装时用户点"仍要运行"即可;star 起量后再买。

## 三、演示 GIF 分镜(30 秒,决定 README 80% 的转化)

工具:macOS 用 Kap 或 Screen Studio(带缩放跟随,效果最好),导出 GIF ≤ 15MB 或 mp4 转 GIF。分辨率 1280×800,深色主题。

| 秒 | 画面 | 要点 |
|---|---|---|
| 0-4 | 新建主机:粘贴 IP + 密码,点连接 | 开场即主张:"填一条 SSH" |
| 4-10 | 环境配置页:一键安装按钮 → 日志滚动 → 全绿 | 快进 4x,展示"全自动" |
| 10-14 | 新建对话:四引擎卡片,选 DeepSeek/国产模型 | 停留 1 秒让人看清四个引擎 |
| 14-26 | 发一句"给这个项目加个 X 功能":流式输出 + 思考气泡 + 红绿 diff 滚出 | 核心画面,占一半时长 |
| 26-30 | 引擎下拉 Codex→国产模型 切一下,继续对话 | 收尾点题"同对话切换" |

录完放 `docs/assets/demo.gif`,取消 README 里的注释行。另录一段 2-3 分钟完整版传 YouTube/B站,README 里放链接。

## 四、渠道发布清单(冷启动周)

发布前:仓库描述与 topics 铺满(`claude-code` `codex` `deepseek` `ssh` `remote-development` `ai-agent` `electron`);Releases 有可下载产物;README 徽章与 GIF 就位;开通 GitHub Sponsors + 爱发电。

| 渠道 | 时间 | 素材 |
|---|---|---|
| Show HN | 周二至四,美西早 8-10 点 | `docs/launch/show-hn.md` |
| Product Hunt | 与 HN 错开一周,周二至四 | `docs/launch/product-hunt.md` |
| Reddit r/ClaudeAI, r/LocalLLaMA, r/selfhosted | HN 同周,角度各异 | 同上文档内附 |
| linux.do | 任意,发帖质量优先 | ⚠️ 该社区明文禁止 AI 生成内容,务必**自己写**;`docs/launch/中文渠道要点.md` 只提供事实素材与提纲,不提供成文 |
| V2EX 创造/分享节点、即刻、少数派 | 错峰各一篇 | 同上,建议本人执笔 |
| awesome 列表 PR | 随时 | awesome-claude-code、awesome-codex、yepanywhere 竞品清单等 |

发布周纪律:所有 issue/评论 2 小时内回复;当天修 bug 当天发 patch 版本——响应速度就是口碑。

## 五、发布后每两周节奏

一个 minor release + 一条社交更新 + 一篇内容(中英轮替)。主题库见《爆款开源与商业化策略》第四节。
