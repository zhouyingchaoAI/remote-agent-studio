## 核心叙事(自己的话复述)

你遇到的真问题:模型/代码在远程机上,本机各种 GUI 工具都够不着;远程机网络不通 OpenAI/Anthropic;想用国产模型但每个 CLI 配置方式都不一样。于是做了这个工具:填一条 SSH 全自动搞定,四引擎同对话切换,国产模型全图形化接入。

## 可用的事实素材

数字:约 7000 行代码,主进程生产依赖只有 ssh2 一个;95+ 单元测试,Ubuntu+macOS 双平台 CI;MIT 协议。

差异点(相对 Happy/CloudCLI/AionUi):它们遥控本机 CLI,这个把远程机当第一公民——自动检测环境、nvm 免 root 装 Node、装 CLI(官方二进制+SHA-256 校验)、SSH 反向隧道代理、认证一键下发、指纹 TOFU 校验、断线重连。

国产模型能力:DeepSeek 官方 Anthropic 端点直驱 Claude Code(v4-pro/v4-flash);grok CLI 统一接 GLM/Kimi/通义/中转站,端点、模型名、协议、Key 全部图形界面配置,Key 存 600 权限 env 文件不落明文,配置块自动生成不覆盖用户自有配置。

技术点(V2EX/开发调优向):每轮对话是一次非交互流式 exec + 精确会话 resume,不抓 PTY;三种 CLI 的流式 JSON 事件统一解析成聊天消息;grok 解析器是防御式实现(schema 未公开)。
