# Product Hunt 发布素材

Name: Remote Agent Studio

Tagline(60 字符内): Your AI coding agents, on any machine over SSH

Description:
A desktop cockpit for coding agents. Paste one SSH connection and it auto-installs Codex / Claude Code / grok CLI on the remote box, configures proxying, syncs auth, and gives you streaming chat with diff review — plus DeepSeek and Chinese LLMs as first-class engines. Open source (MIT).

Topics: Developer Tools, Artificial Intelligence, Open Source, GitHub

Gallery 素材清单:30 秒演示 GIF/视频、四引擎切换截图、diff 审阅截图、国产模型端点配置面板截图、架构图。

Maker's first comment:
Every agent GUI assumes your agent runs locally. Real work lives on GPU boxes, intranet servers, cloud VMs. So I made the remote machine a first-class citizen: one SSH entry → fully working agent environment. Ask me anything about the SSH/proxy plumbing!
