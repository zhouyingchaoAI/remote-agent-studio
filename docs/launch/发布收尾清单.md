# 发布收尾清单(逐条粘贴即可)

> 代码、文档、流水线、tag 都已就绪。以下是需要你在自己环境执行的最后几步,均已备好可复制内容。

## 1. 确认代码已推送

```bash
cd ~/Documents/codex/remote-agent-studio
git log origin/main -1 --oneline   # 应看到 b684d4b feat: v0.2.0 ...
```

## 2. 触发首个 Release(三平台自动构建)

tag 已在本地打好,推送即可:

```bash
git push origin v0.2.0
```

推送后去仓库 Actions 页看 `Release` 工作流跑三平台构建,完成后会生成一个 **draft release**,进去补上 release notes(见第 5 节成稿)后点 Publish。
未配 Apple 证书时 mac 包是未签名的,可正常用于测试;签名配置见 `docs/发布指南.md` 第二节。

## 3. 填仓库描述与 Topics(GitHub 网页 → 仓库首页右上「About」齿轮)

Description(粘贴):

```
SSH-native desktop cockpit for coding agents. One-click remote setup, streaming chat, and first-class DeepSeek / GLM / Kimi / Qwen support — for Codex, Claude Code & Chinese LLMs.
```

Topics(逐个添加):

```
claude-code  codex  deepseek  ai-agent  ssh  remote-development  electron  llm  coding-assistant  glm  kimi  qwen
```

同时勾选 "Use your GitHub Pages website" 下方的 Releases、Packages 视情况;确保 "Include in the home page" 里 About 展示 topics。

## 4. 开启社区功能(仓库 Settings)

- Settings → General → Features:勾选 **Issues**、**Discussions**(社区问答阵地)。
- Settings → 添加仓库 Social preview 图(可用演示 GIF 的一帧,提升分享点击率)。
- 首页确认 issue/PR 模板生效(`.github/` 已就绪,推送后自动可用)。

## 5. Release Notes 成稿(v0.2.0,粘进 draft release)

```markdown
## Remote Agent Studio v0.2.0

First public release. An SSH-native desktop app that turns any remote box into a
working home for your coding agents.

### Highlights
- **Four engines, one conversation** — Codex, Claude Code, DeepSeek, and Chinese
  LLMs (GLM / Kimi / Qwen via grok CLI), with mid-conversation switching and
  automatic context handoff.
- **First-class Chinese LLM support** — DeepSeek V4 through its official
  Anthropic-compatible endpoint; any OpenAI-compatible provider or relay added
  from the GUI. Keys live in a 600-permission env file, never in plaintext config.
- **One SSH entry → working agent** — auto env detection, rootless Node + CLI
  install, proxy auto-config (reverse tunnel / LAN), auth sync, host fingerprint
  TOFU, auto-reconnect.
- **Desktop-grade chat** — token streaming, reasoning/tool/diff/cost bubbles,
  queued sends, auto-approve with a circuit breaker, search & Markdown export.

### Install
Download the build for your OS below, or run from source (`npm install && npm run dev`).
macOS builds are currently unsigned — right-click → Open on first launch.

MIT licensed. Feedback and provider PRs welcome — see CONTRIBUTING.md.
```

## 6. 录演示 GIF(README 转化率关键,分镜见 docs/发布指南.md 第三节)

工具建议 Screen Studio 或 Kap,1280×800 深色主题,30 秒,导出到 `docs/assets/demo.gif`,然后取消 README 两处 `<!-- ...demo.gif -->` 注释并提交:

```bash
git add docs/assets/demo.gif README.md README.zh-CN.md
git commit -m "docs: add demo gif"
git push
```
