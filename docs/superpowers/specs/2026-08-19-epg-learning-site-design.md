# EPG 访谈学习网站设计

## 目标

为 EPG 访谈准备提供一个离线可用、文字作答的学习网站。答案采用《EPG 访谈极简口语版》中的“够用回答”，帮助用户用自然、简单的中文表达，而不是逐字背诵。

## 范围

- 33 道固定题目，每题包含问题、记忆钩子、够用回答和用于反馈的核心关键词。
- 学习模式：顺序或随机浏览题目，显示记忆钩子和答案，标记“已掌握”或“待复习”。
- 模拟面试：随机连续出题；用户输入文字回答后，系统比对核心关键词，展示已覆盖内容、建议补充点和简短参考回答，然后进入下一题。
- 进度中心：掌握度、最近练习、需复习题、当前模拟记录。
- 进度、答题文本和模拟记录都使用 `localStorage` 保存；不传输数据，不需要账号、后端或 API。

## 不在范围

- 语音输入、语音评分、真实大模型点评、登录、多端同步、服务端数据库。

## 架构

在仓库内新增独立 Vite + React 单页应用目录 `epg-learning/`，避免与现有 Remote Agent Studio 桌面端功能和 Electron API 耦合。应用由以下模块构成：

- `src/data/questions.js`：题库的唯一数据源。
- `src/lib/evaluation.js`：可测试的关键词覆盖判断和反馈文案生成。
- `src/lib/storage.js`：`localStorage` 读写、版本与安全回退。
- `src/App.jsx`：三个视图及其导航。
- `src/components/`：学习卡、模拟面试、进度中心等独立组件。

## 交互与数据流

1. 首次启动载入静态题库及浏览器历史状态；无状态时创建空进度。
2. 学习模式的“掌握/待复习”立即更新题目状态并写入本地。
3. 模拟面试按未练优先、随机顺序取题。提交文字后，应用将用户内容归一化，再与该题的核心关键词匹配。
4. 反馈以覆盖数量呈现，例如“说得不错：已覆盖 3 个要点”“再补一个点：试点验证”。它只报告可解释的关键词结果，不冒充 AI 语义评分。
5. 本轮记录追加到会话时间线并自动保存；用户可继续下一题或结束本轮查看总结。

## 体验和错误处理

- 移动端优先、适配桌面；单页内切换，无需刷新。
- 空白回答提示“先写一句再提交”，不写入记录。
- `localStorage` 不可用或数据损坏时显示友好提示，保留本次临时练习，不让页面崩溃。
- 进度中心提供“清空练习记录”确认操作。

## 验证

- 对关键词标准化、覆盖判断、空回答和本地存储回退写 Node 单元测试。
- 构建生产包，运行测试与 ESLint。
- 用浏览器检查学习、模拟、刷新恢复和移动布局。
